# TinyDie

A pocket electronic die built around the **ATtiny412**, an 8-pin tinyAVR with 4 kB of flash and 256 B of RAM.
Press the button and the pips tumble. Let go and they slow down and land on a number.
After a few seconds the chip drops into power-down sleep (~0.1 µA), so it runs from a single CR2032 with no power switch.

- **MCU:** ATtiny412-SSNR (SOIC-8)
- **Board:** 45 × 45 mm, 2-layer, GND pour on both sides. Designed in **KiCad 10**.
- **Power:** CR2032, holder on the back
- **BOM:** ≈ $1.75 per board; ≈ $15–31 for 5 boards including PCBs and shipping. See [BOM.md](BOM.md).
- **Checks:** ERC 0 errors, DRC 0 violations, 0 unconnected, 0 schematic↔PCB parity issues

## How it works

Six possible faces, but only **four** independent LED groups are needed, because pips always come in fixed pairs:

| Group | Pin | LEDs | Lit on |
|---|---|---|---|
| A | PA1 (pin 4) | top-left + bottom-right | 2, 3, 4, 5, 6 |
| B | PA2 (pin 5) | top-right + bottom-left | 4, 5, 6 |
| C | PA3 (pin 7) | middle-left + middle-right | 6 |
| D | PA6 (pin 2) | centre | 1, 3, 5 |

That leaves PA7 (pin 3) for the button and PA0 (pin 6) for UPDI programming. All 6 I/O pins are used.

Each LED has its own 330 Ω resistor, so (3.0 V − 2.0 V) / 330 Ω ≈ 3 mA. A "6" draws about 18 mA, which a CR2032 handles fine in short bursts.
Randomness comes from a free-running timer sampled while your finger is on the button, mixed into an xorshift16 generator.

**Battery life, rough numbers:** one roll is about 5 s at about 12 mA on average, roughly 0.017 mAh.
A 220 mAh cell gives on the order of 10,000 rolls. Sleep current is negligible.

```
firmware/            bare-metal C (avr-gcc + avr-libc), Makefile
hardware/
  tinydie.kicad_pro/.kicad_sch/.kicad_pcb   the KiCad project
  scripts/           generators: gen_sch.py, gen_pcb.py, router.py, build.sh
  fab/               Gerbers + drill (zip), BOM, pick-and-place
  docs/              schematic PDF/SVG, PCB SVGs, renders
  reports/           ERC + DRC reports
BOM.md               costed bill of materials (budget ≤ $35)
JOURNAL.md           design log
```

The KiCad files are generated by scripts, so every design change is a diff in `hardware/scripts/`.
Open `hardware/tinydie.kicad_pro` in KiCad to view or edit them by hand.

```sh
hardware/scripts/build.sh   # regenerate sch + pcb, run ERC/DRC, export fab files
```

## Firmware

```sh
cd firmware
make          # needs avr-gcc + avr-libc (Arch: pacman -S avr-gcc avr-libc)
make flash    # needs pymcuprog (pip install pymcuprog) and a SerialUPDI adapter
```

Current build: **447 bytes** of the 4096-byte flash.

### Programming (SerialUPDI)

Use any USB-serial adapter running at 3.3 V:

```
adapter TX ──[1 kΩ]──┬── J1 "U" (UPDI)
adapter RX ──────────┘
adapter 3V3 ───────────── J1 "V"
adapter GND ───────────── J1 "G"
```

**Take the coin cell out before you connect the programmer's 3V3.**

## Ordering

1. Upload `hardware/fab/tinydie-gerbers.zip` to your PCB fab: 2 layers, 1.6 mm, any colour.
   Smallest feature is 0.2 mm clearance and 0.3 mm vias, well within standard rules.
2. Buy the parts in [BOM.md](BOM.md).
3. Solder the front first (U1, C1, R1–R7, D1–D7, SW1). The LEDs' cathode mark faces the left side of the board.
   Then solder J1, then the battery holder on the back.
